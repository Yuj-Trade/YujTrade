## Post-run verification: 2026-10-23 live run

A real QuickAnalyze run (10:03:50-10:07:01) after the phase work exposed three
defects that the unit tests had not caught, plus one previously blocked item
that became diagnosable. All four are now fixed.

### Defect 1: Binance futures breaker blocked spot (regression from Phase 4)

- Symptom: 6 x `Circuit breaker is OPEN` on `api.binance.com/api/v3/depth`,
  which had been working before Phase 4.
- Cause: `BinanceFetcher` used one `CircuitBreaker` for both `api.binance.com`
  and `fapi.binance.com`. Phase 4 made futures timeouts count toward the
  breaker, so futures failures opened the breaker and took spot down with them.
- Fix: `futures_circuit_breaker` is a separate instance, selected by host in
  `_fetch`. `a03cc85`.
- Test: `test_futures_timeouts_do_not_block_spot_requests`.
